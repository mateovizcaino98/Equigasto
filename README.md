# 💰 EquiGasto

### Una aplicación web para administrar gastos compartidos de forma clara, transparente y sencilla.

---

## 📖 Problema

Existen muchos motivos por los cuales un grupo de personas puede llegar a compartir gastos. Ya sea porque son roomates, compartieron un viaje, existe un proyecto en el que están trabajando juntos, o una simple salida entre amigos. Muchas veces estas situaciones vienen acompañadas de desorganización, desentendimiento o desacuerdos ¿Quién pagó qué? ¿Quién consumió qué? ¿Todos deben pagar lo mismo? ¿Cuánto debe cada uno?
